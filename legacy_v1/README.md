# Legacy v1 Artifacts

**WARNING: PRE-AUDIT ARTIFACTS**

The files and directories in this folder are legacy artifacts from the initial (v1) implementation phase prior to the mandatory self-audit. 

They are kept here for historical reference and documentation of the project's evolution (e.g., for the paper's methodology section). 

**IMPORTANT NOTE:**
These files represent unverified, mock, or hardcoded implementations (such as the original deterministic `repair_loop.py` and the hardcoded `mmio_stubber.py`). The artifacts in `output/` (including old PoVs, advisories, and harnesses) were generated by this unverified code. 

**None of these files should be considered verified, working code, and they should not be used in the v2 pipeline.**
